# 📊 Estadistica_AndreeaIstrate

Este proyecto proporciona métodos para calcular medidas estadísticas básicas como la **media aritmética**, la **varianza** y la **desviación estándar** a partir de una lista de números ingresada por el usuario.

## ✨ Características

✔️ **Cálculo de la media aritmética** 📈  
✔️ **Cálculo de la varianza** 📊  
✔️ **Cálculo de la desviación estándar** 📉  
✔️ **Interfaz de consola con menú interactivo** 🎛️  

## 🔧 Requisitos

🖥️ **Java 8 o superior**  

## 🚀 Instalación y Ejecución

1️⃣ Clonar este repositorio o descargar el archivo fuente.  
2️⃣ Compilar el archivo `Estadistica_AndreeaIstrate.java`:

   ```sh
   javac Estadistica_AndreeaIstrate.java
   ```

3️⃣ Ejecutar la clase principal:

   ```sh
   java org.unir.javabeans.Estadistica_AndreeaIstrate
   ```

## 🎮 Uso

Cuando ejecutes el programa, se presentará un menú en la consola con las siguientes opciones:

1️⃣ **Media Aritmética**: Calcula el promedio de los números ingresados.  
2️⃣ **Varianza**: Calcula la varianza de los números ingresados.  
3️⃣ **Desviación Estándar**: Calcula la desviación estándar de los números ingresados.  
4️⃣ **Salir**: Termina la ejecución del programa.  

📌 El usuario debe ingresar la cantidad de números y luego los valores correspondientes para realizar los cálculos.  

### 📌 Ejemplo de Uso

```
Seleccione una opción:
1. Media Aritmética
2. Varianza
3. Desviación Estándar
4. Salir

Ingrese la cantidad de números:
3
Ingrese los números:
5
10
15

La media aritmética es: 10.0
```
