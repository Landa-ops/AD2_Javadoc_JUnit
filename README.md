# Calculadora de Operaciones Matemáticas

Esta es una aplicación Java que permite realizar diversas operaciones matemáticas, como divisiones, cálculo de inversos y raíces cuadradas. La aplicación presenta un menú interactivo en la consola para que el usuario seleccione la operación deseada.

## Características

- **División de dos números reales**: Realiza la división de dos números decimales.
- **División de dos números enteros**: Realiza la división de dos números enteros.
- **Inverso de un número real**: Calcula el inverso (1/x) de un número decimal.
- **Raíz cuadrada de un número**: Calcula la raíz cuadrada de un número.
- **Interfaz de menú interactivo**: Permite al usuario seleccionar y realizar múltiples operaciones hasta que decida salir.

## Requisitos

- Java Development Kit (JDK) 8 o superior.
- Una terminal o consola para ejecutar la aplicación.

## Instrucciones de Uso

1. **Clona o descarga el repositorio** en tu máquina local.
2. **Compila el código fuente**:
   ```bash
   javac DivisiónCesarAAlcazarRomero.java
 3. **Ejecuta la aplicación**:

    java Main

4. **Sigue las instrucciones en pantalla**:

        Selecciona una opción del menú.

        Ingresa los números solicitados.

        Observa el resultado de la operación.

        Repite el proceso o selecciona la opción "Salir" para finalizar.   

## Estructura del Código

    Clase Division: Contiene los métodos para realizar las operaciones matemáticas.

    Método main: Gestiona el menú interactivo y la interacción con el usuario.

    Método solicitarEntero: Valida que la entrada del usuario sea un número entero.
